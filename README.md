# Müvekkil Kasa Defteri — Geliştirilebilir Kaynak

Electron + React + TypeScript masaüstü uygulaması.

## Komutlar

- `npm run dev` — geliştirme
- `npm run build` — üretim derlemesi
- `npm run dist:win` — Windows NSIS kurulum paketi
- `npm run split-css` — referans CSS'i parçalara ayırır

## Referanslar

- Çalışan kurtarma: `../Müvekkil Kasa defteri/asar-extract`
- Ofis Kasası build kalıntısı: `../Müvekkil Kasa defteri/out`
